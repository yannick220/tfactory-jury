T·Factory V44 — Gestion des pitchs sautés

1. Déployer les fichiers du ZIP à la racine de GitHub Pages.
2. Exécuter SUPABASE-V44-PITCHS-SAUTES.sql dans Supabase SQL Editor après V43.
3. Dans Administration > Jurés & validations, choisir le pitch puis « Passer ce pitch ».
4. Un pitch sauté ne reçoit ni note ni financement ; les pitchs suivants sont publiables automatiquement.
5. Réactivation possible, sous réserve de reprendre la séquence normale de publication.

Les résultats déjà validés ne peuvent pas être sautés. La valorisation continue avec les notes des pitchs effectivement réalisés ; les pondérations disponibles sont normalisées si une catégorie manque.
