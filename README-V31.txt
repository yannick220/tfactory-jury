T·Factory V31 — 0 à 6 000 € linéaires, chaque note /20 multipliée par 300. Financement final = moyenne de tous les jurés (nombre variable), arrondie uniquement à la dizaine supérieure. Notes historiques conservées. Les notes agrégées restent pondérées 70 % pro / 30 % pédagogique pour les classements ; le financement est une moyenne simple des montants individuels. IMPORTANT : exécuter SUPABASE-V31-FINANCEMENT-LINEAIRE.sql dans Supabase SQL Editor avant déploiement, sinon les nouvelles saisies risquent d’être refusées par l’ancienne validation du barème. Les pitchs historiques sans détails individuels sont recalculés depuis leur note agrégée, ce qui ne permet pas de reconstituer une moyenne individuelle exacte.
